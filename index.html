PY
Application de Jeu 2D
Python · Bibliothèque Pygame

Conception complète d'un environnement de jeu interactif en deux dimensions. Gestion rigoureuse de la boucle principale (Game Loop), du rafraîchissement d'affichage, et de l'écoute événementielle matérielle.

Description technique

Ce projet met en œuvre les principes fondamentaux de la programmation événementielle et séquentielle sous Python. L'application gère de façon fluide les interactions utilisateur, la détection précise des boîtes de collision (hitboxes), ainsi que l'optimisation des cycles CPU via le contrôle du taux de rafraîchissement (FPS framerate cibles).

Extrait de la structure de contrôle principale (`main.py`)
import os import pygame from ui_elements import StartScreen, GameOverScreen, FamineScreen, BrokeScreen import engine def runPyGame(): pygame.display.init() pygame.font.init() fpsClock = pygame.time.Clock() screen = pygame.display.set_mode((0, 0), pygame.FULLSCREEN) pygame.display.set_caption('Make Country Great Again') current_w, current_h = get_width(), get_height() start_screen = StartScreen(current_w, current_h) game_over_screen = GameOverScreen(current_w, current_h) engine.init_game(broke_screen) dt = 1/60.0 # Delta fixe ciblé par frame while True: game_state = engine.state["game_state"] if game_state == "START": screen = start_screen.update(dt, screen) start_screen.draw(screen) if start_screen.game_started: engine.state["game_state"] = "PLAYING" elif game_state == "PLAYING": screen = engine.update(dt, screen) engine.draw(screen) elif game_state == "GAMEOVER": screen = game_over_screen.update(dt, screen) game_over_screen.draw(screen) if game_over_screen.game_retry: engine.init_game() engine.state["game_state"] = "PLAYING" dt = fpsClock.tick(60)

GO
Project Particles
Go · Architecture Système & Rendu

Développement d'un moteur de rendu de particules hautement performant en Go, basé sur une architecture découplée et modulaire

Description technique

Développé à l'aide de structures performantes et typées en langage Go, ce système assure une simulation graphique fluide de centaines de particules colorées indépendantes : gestion de la configuration (`config`), logique comportementale des entités (`particle`), moteur d'initialisation (`game`), routines logiques (`update`), et fonctions d'affichage graphique de bas niveau (`draw`).

Extrait de l'algorithme de mise à jour des entités (`update.go`)
package particles import ( "math" "project-particles/config" "project-particles/particle" "github.com/hajimehoshi/ebiten/v2" ) func (s *System) Update() { var spawnX, spawnY float64 if config.General.MobileGenerator { mx, my := ebiten.CursorPosition() spawnX, spawnY = float64(mx), float64(my) } else { spawnX = float64(config.General.SpawnX) spawnY = float64(config.General.SpawnY) } // Génération de nouvelles particules for i := 0; i < int(config.General.SpawnRate); i++ { pf := particle.Boucle() pf.PositionX, pf.PositionY = spawnX, spawnY s.Content.PushFront(&pf) } // Mise à jour dynamique de la physique et de la gravité for uneParticule := s.Content.Front(); uneParticule != nil; uneParticule = uneParticule.Next() { p, ok := uneParticule.Value.(*particle.Particle) if ok { if config.General.LifeTime { p.LifeTime-- if p.LifeTime <= 0 { s.Content.Remove(uneParticule); continue } } if config.General.Gravité { p.SpeedY += (9.81 / 60) } p.PositionX += p.SpeedX p.PositionY += p.SpeedY } } }

HTM
Interface E-Commerce (N'Brick & Brick)
HTML5 · CSS3 · Intégration Graphique

Intégration rigoureuse d'un site de vente en ligne de briques de construction, s'appuyant sur des layouts bidimensionnels CSS Grid avancés.

Description technique

Développement conforme aux fichiers sources structurels fournis. Ce projet met en valeur la maîtrise des techniques modernes d'intégration CSS sans dépendance JavaScript superflue. L'agencement exploite la puissance de CSS Grid pour la grille de produits modulaires (structure native à 2 colonnes) combinée à un agencement Flexbox pour la barre d'en-tête (Header) et la gestion latérale du panier d'achat interactif. Il intègre de façon sémantique l'identité de marque via l'actif graphique référencé sous le nom brick-removebg-preview.png.
